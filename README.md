# Call Center Dashboard

## Project Overview
A simple Excel dashboard created to analyze call center performance and customer service metrics.

## Key Metrics
- Total Calls
- Average CSAT Score
- Average Call Duration
- SLA Performance
- Customer Sentiment Analysis

## Dashboard Features
- Call Volume Trends
- Sentiment Breakdown
- Call Reason Analysis
- Channel-wise Performance
- State-wise Distribution
- Interactive Filters and Slicers

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers

## Files
- `Call Center Dashboard.xlsx` – Dashboard file
- `call center data.xlsx` – Source dataset

## Purpose
To provide a clear and interactive view of call center operations, helping identify trends, customer satisfaction levels, and service performance.
